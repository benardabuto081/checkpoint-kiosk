# Checkpoint Kiosk

Event check-in kiosk service for Solstice Events Co. — PLP Group 90, Meridian Pivot.

## What this is
Staff scan an attendee's QR code to check them in and print a badge.
Originally built against a synchronous vendor API; pivoted mid-sprint
to an asynchronous message-queue + webhook model per a non-negotiable
client requirement change.
